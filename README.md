
# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple
web-based application designed to help users record
and organise their daily expenses.

This project is being developed progressively as part
of the weekly HTML, CSS and JavaScript learning tasks.

## Week 1 and Week 2 Features

### 1. Page Structure
Created the main webpage using HTML5 with a heading,
description and organised sections.

### 2. Add Expense Form
Created an expense form containing:
- Expense name input
- Amount input in Kenyan Shillings
- Category dropdown
- Date input
- Add Expense button

### 3. Expense Table
Created an HTML table displaying sample expense
records under four columns:
- Name
- Amount
- Category
- Date

### 4. Multimedia Content
Added a budget tracker logo using the HTML image tag
and embedded a personal budgeting video using an iframe.

### 5. Interactive Elements
Added a collapsible instruction section using
HTML details and summary elements.

### 6. CSS Styling
Used CSS to style the webpage, form, expense table,
buttons and other sections.

### 7. Advanced CSS Selectors
Practised:
- Descendant selectors
- Direct child selectors
- Positional pseudo-classes
- Negation pseudo-classes
- Focus pseudo-classes
- Hover pseudo-classes

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Google Chrome
- GitHub
